{{운영자명}}(이하 "운영자")은 Exam Loop(이하 "서비스")를 제공하면서 이용자의 개인정보를 중요하게 취급하며, 개인정보 보호법 등 관련 법령을 준수합니다.

## 1. 수집하는 개인정보 항목과 수집 방법

서비스는 로그인 없이도 모든 학습 기능을 사용할 수 있으며, 이 경우 학습 기록은 이용자 기기에만 저장되고 운영자에게 전송되지 않습니다.

계정을 연결한 경우 아래 항목을 수집합니다.

| 구분 | 항목 | 수집 시점 |
|---|---|---|
| 필수 | 이메일 주소, 비밀번호(암호화 저장), 사용자 식별자 | 회원가입·로그인 시 |
| 필수 | 학습 기록(문제 풀이 이력, 복습 일정, 저장한 문제, 등록한 시험) | 계정 연결 후 학습 시 |
| 선택 | 시험 요청 내용(시험명, 주관 기관, 등급, 공식 링크, 요청 사유), 요청 투표, 신고 내용 | 이용자가 직접 작성·전송 시 |
| 선택 | 기기 푸시 토큰, 기기 플랫폼(iOS/Android) | 알림 권한을 허용한 경우 |

서비스는 광고 식별자, 위치 정보, 연락처, 사진, 결제 정보를 수집하지 않습니다.

## 2. 개인정보의 이용 목적

- 회원 식별·인증 및 계정 관리
- 여러 기기 간 학습 기록 동기화
- 시험 요청 접수·중복 병합·처리 상태 안내
- 학습 리마인더 및 요청 처리 결과 알림 발송
- 부적절한 게시물·부정 이용 대응 및 서비스 운영 안정성 확보

## 3. 보유 및 이용 기간

- 계정 정보와 학습 기록: 회원 탈퇴 즉시 삭제
- 이용자가 등록한 시험 요청: 다른 이용자의 투표가 반영된 공동 수요 정보이므로 요청 내용은 유지하되, 탈퇴 시 작성자 식별 정보와 자유 서술(요청 사유)을 삭제하여 익명화
- 신고 내용: 처리 완료 후 {{신고 기록 보존 기간, 예: 1년}} 보존 후 삭제
- 운영 감사 기록: {{감사 기록 보존 기간, 예: 1년}} 보존 후 삭제
- 관련 법령에서 별도 보존 기간을 정한 경우 해당 기간을 따릅니다.

## 4. 회원 탈퇴 및 개인정보 삭제 방법

### 앱에서 직접 삭제

앱의 설정 → 계정 → 계정 삭제에서 직접 탈퇴할 수 있습니다. 탈퇴 시 계정, 학습 기록, 복습 일정, 저장한 문제, 요청 투표, 푸시 토큰이 즉시 삭제되며 복구할 수 없습니다. 기기에 저장된 학습 데이터도 함께 삭제됩니다.

### 앱 없이 삭제 요청

앱을 설치하지 않았거나 앱에 접근할 수 없는 경우, {{문의 이메일}}로 가입한 이메일 주소와 함께 계정 삭제를 요청할 수 있습니다. 본인 확인 후 영업일 기준 7일 이내에 처리하고 결과를 회신합니다.

### 삭제되는 항목과 보존되는 항목

| 구분 | 항목 |
|---|---|
| 즉시 삭제 | 계정·이메일, 학습 기록, 복습 일정, 저장한 문제, 등록한 시험, 요청 투표, 푸시 토큰 |
| 익명화 후 유지 | 이용자가 등록한 시험 요청의 시험명·투표 집계(작성자 식별 정보와 요청 사유는 삭제) |
| 기간 경과 후 삭제 | 신고 처리 기록, 운영 감사 기록(제3조의 보존 기간 적용) |

## 7. 이용자의 권리와 행사 방법

이용자는 언제든지 개인정보 열람·정정·삭제·처리정지를 요구할 수 있습니다. 앱 내 계정 삭제 기능을 이용하거나 아래 연락처로 요청할 수 있으며, 요청은 지체 없이 처리합니다. 학습 데이터는 앱의 설정 → 데이터 → 학습 데이터 내보내기에서 이용자가 직접 JSON 형식으로 내려받을 수 있습니다.
